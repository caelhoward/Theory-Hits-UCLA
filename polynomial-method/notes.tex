\subsection{Examples and Properties}
Firstly, we know that we can select a set that has size $2^n$ that satisfies that there are no $3AP$'s. We argue that $A = \{0,1\}^n$ has no $3AP$'s.
\begin{proof}
Assume that there was some $a,b,c$ such that they form a nontrivial $3AP$. The argument is relatively straightforward, but we know that if $a_i + b_i$ is $1$, $c_i$ cannot be a three $AP$, if $a_i + b_i = 0$ then $a_i=b_i=c_i=0$ so they must be the same bit and if $a_i + b_i = 2$ then $c_i = b_i = a_i = 1$. So either the three numbers are the same or they do not form a $3AP$.
\end{proof}
This provides a lower bound for $r_3(\mathbb{F}_3^n)$:
$$r_3(\mathbb{F}_3^n) \geq 2^n = N^{\log_3 2} \approx N^{0.63}$$

    a_i + b_i + c_i &\equiv 0 \mod 3
\end{align*}
This equation is satisifed when all $a_i = b_i = c_i$ or each value is unique.

\begin{definition}
    We say that a \textbf{Rank} of a matrix $M$ ($rank(M)$) is the number of linearly independent columns or number of linearly independent rows of the matrix. Another way to think about it is the number of rank $1$ matrices that add up to $M$:
    $$Rank(M) = \underset{r}{\min} \{ M = M_1 + ... + M_r\}$$
    Where all $M_i$ are rank 1 matrices. 
\end{definition}
Knowing that $rank(M) = r$, we can write $M$ as the following:
$$M = f_1 g_1^T + ... + f_r g_r^T$$
Where each $f_i$ represents one of the linearly independent columns and each $g_i$ represents one of the linearly independent rows. This decomposition has each $M_i = f_i \cdot g_i^T$. We can therefore redefine rank for matrices in $\mathbb{F}_3^{n \times n}$ as the following:
\begin{align*}
    Rank(M) = \min_{r} \Big\{  &\exists f_1, \ldots, f_r: [N] \longrightarrow \mathbb{F}_3, \\
    &\exists g_1, \ldots, g_r: [N] \longrightarrow \mathbb{F}_3 \\
    &\mid M(x,y) = f_1(x) g_1(y) + \cdots + f_r(x) g_r(y)\ \forall x,y \in [N]\Big\}
\end{align*}

We should also think of matrices as a function that takes in two inputs and outputs a value. Furthermore, for a tensor, we can think of it as a function that takes in three inputs and outputs a value. For tensor rank, the general notion is as follows:
\begin{definition}
    We say that a \textbf{Rank} of a tensor $T$ ($rank(T)$) is the number of rank 1 tensors that add up to $T$:
    $$Rank(T) = \underset{r}{\min} \{ T = T_1 + ... + T_r\}$$
    Where all $T_i$ are rank 1 tensors.
\end{definition}
We draw a parallel with the second definition of matrix rank and define the following for tensors:
\begin{align*}
    Rank(T) = \min_{r} \Big\{  &\exists f_1, \ldots, f_r: [N] \longrightarrow \mathbb{F}_3, \\
    &\exists g_1, \ldots, g_r: [N] \longrightarrow \mathbb{F}_3, \\
    &\exists h_1, \ldots, h_r: [N] \longrightarrow \mathbb{F}_3, \\
    &\mid T(x,y,z) = f_1(x) g_1(y) h_1(z) + \cdots + f_r(x) g_r(y) h_r(z)\ \forall x,y,z \in [N]\Big\}
\end{align*}
You think of a rank one tensor as a function that can be written as a product of three functions, each of which takes in one of the three inputs. We will be interested in the following tensor:
$$\mathbb{I}(x,y,z) = \begin{cases}  1 & \text{if } x=y=z\\
0 & \text{otherwise} \end{cases}$$
Firstly, we know that $rank(\mathbb{I}^{N \times N}) \leq N$ because we can write $\mathbb{I}$ as the sum of $N$ rank one tensors. Secondly, we know that $rank(\mathbb{I}^{N \times N \times N}) \leq N$ where $f_i(x) = g_i(y) = h_i(z) = 1$ if $x=y=z=i$ and $0$ otherwise. For each $f_i, g_i, h_i$ we just say $f_i(x) = 1$ if $x=i$ and $0$ otherwise.
\subsubsection{Thought Experiment}
Say we have a matrix $M$ which we think about as a function $M(x,y)$. If two parties are trying to figure out the value of $M[x,y]$ where one party has $x$ and the other has $y$, one easy protocol is having the first party send $x$ to the second party and having the second party compute $M[x,y]$. However, if $M$ has low rank, we can do better. We can write $M$ as the sum of $r$ rank one matrices:
$$M = f_1 g_1^T + ... + f_r g_r^T$$
In this case, we can have Alice (party 1) send $f_i(x)$ for all $i$ to Bob. Since $f_i(x)$ is either $[0,1,2]$, the complexity of this protocol is just $O(r)$ opposed to $O(\log N)$.
\bigskip

Consider the case with three parties trying to compute the tensor $M^{n \times n \times n}$. If $M$ has low rank, we can write $M$ as the sum of $r$ rank one tensors:
$$M = f_1 g_1 h_1 + ... + f_r g_r h_r$$
In this case, we can have Alice and Bob send $f_i(x)$ and $g_i(y)$ for all $i$ to Charlie, and Charlie can compute $M[x,y,z]$ by computing $f_i(x) g_i(y) h_i(z)$ for all $i$. The complexity of this protocol is just $O(r)$ opposed to $O(\log N)$ once more.
\subsubsection{New Notion of Tensor Rank}
We define a new notion of tensor rank called Slice Rank. To motivate this, we make a continuation of the previous thought experiment where each round, two players can get together and send information to the third player. We define the protocol as:
\begin{itemize}
    \item Alice has $x$, Bob has $y$, and Charlie has $z$.
    \item Start with Alice and Bob in a room and Charlie in another room. Alice and Bob can talk to each other but not to Charlie.
    \item In other rounds, any two players can get together and talk to each other but not to the third player.
\end{itemize}
To formalize this idea, we define the following:
\begin{definition}
    We say that a \textbf{Slice Rank} of a tensor $T$ ($srank(T))$\\

    \[
    \mathrm{SRank}(T)
    =
    \min \left\{ r :
    \begin{array}{l}
    \exists\ r_1,r_2,r_3 \text{ with } r_1+r_2+r_3=r, \\[4pt]
    f_1,\dots,f_{r_1} : [M]\to\mathbb{F}, \\
    \widetilde f_1,\dots,\widetilde f_{r_1} : [M]\times[M]\to\mathbb{F}, \\[4pt]
    g_1,\dots,g_{r_2} : [M]\to\mathbb{F}, \\
    \widetilde g_1,\dots,\widetilde g_{r_2} : [M]\times[M]\to\mathbb{F}, \\[4pt]
    h_1,\dots,h_{r_3} : [M]\to\mathbb{F}, \\
    \widetilde h_1,\dots,\widetilde h_{r_3} : [M]\times[M]\to\mathbb{F}, \\[6pt]
    \text{such that } \\
    \begin{aligned}
    T(x,y,z) = \sum_{i=1}^{r_1} f_i(x)\widetilde f_i(y,z) + \sum_{i=1}^{r_2} g_i(y)\widetilde g_i(x,z) \\
    \quad + \sum_{i=1}^{r_3} h_i(z)\widetilde h_i(x,y)
    \end{aligned}
    \end{array}
    \right\}.
    \]
\end{definition}
We end this lecture by explaining that $SRank(T) \leq Rank(T)$ since we can just define $\widetilde{f_i}$ as $g_i \cdot h_i$.

First, we define a tensor assosiated with $3AP$ sets, and show that if there exists a large $3AP$ free set, some property of the tensor is violated. Consider the following function for checksum:
\begin{align}
    CS: \mathbb{F}_3^n \times \mathbb{F}_3^n \to \mathbb{F}_3 \rightarrow \{0,1\}\\
    CS(x,y,z) = \begin{cases} 1 & \text{if } x+y+z = 0\\
    0 & \text{otherwise} \end{cases}
\end{align}
For this function, we can think of it like a cube with $1$'s along the diagonal, and $0$'s in other locations unless the three inputs are all different, or all sum to $0$ mod $3$. Consider a subset $S \subseteq \mathbb{F}_3^n$ such that $S$ is a $3AP$ free set, meaning no $x+y+z=0$ for distinct $x,y,z \in S$. This implies that $CS(x,y,z) = 1$ if and only if $x=y=z$ (We think of the subset $S$ as taking a subcube of the tensor by removing the $i$th element row). Because of this, the remaining tensor representing $S$ must be the identity tensor. In otherwords:
$$CS_{S \times S \times S} = \mathbb{I}^{S \times S \times S}$$
\subsection{Properties of Identity Tensor}
We will prove the three following properties:
\begin{enumerate}
    \item $SRank(\mathbb{I}_{M\times M\times M}) = M$
    \item $SRank(\text{ sub-tensors }) \leq SRank(\text{ main tensor })$
    \item $SRank(CheckSum) \leq 3^{cn}$ where $(c < 1)$
\end{enumerate}
This is sufficient to demonstrate that there does not exist a big $S$. Since $CS_{S\times S\times S} = |S|$ from property $1$. Then we know that $|S| \leq SRank(CS)$ by 2. If we bound $SRank(CS)$, we therefore have a bound for $|S|$.
\subsubsection{Bounding Slice Rank of Identity Tensor}
We aim to show that the slice rank of the identity tensor is $M$. Firstly, we know that for matrices we can easily show that $I_M$ has rank $M$ since there are $M$ linearly independent rows/columns. We, however, cannot extend this argument to Tensors so we try another approach.
\lemma{$SRank(\mathbb{I}_{M \times M \times M}) = M$}
\bigskip

First, consider the following tensor $T: [M] \times [M] \times [M] \rightarrow \{0,1\}$
$$T(x,y,z) = \begin{cases} 1 & \text{if } x+y+z \text{ is even}\\0 & \text{otherwise} \end{cases}$$
The above has a $SRank$ of 2:
$$T(x,y,z) = \mathds{1}(x \text{ is even}) \cdot \mathds{1}(y+z \text{ is even}) + \mathds{1}(x \text{ is odd })\cdot \mathds{1}(y+z \text{ is odd })$$
We cannot extend proofs that $I_{M \times M}$ has rank $M$ that rely on linear independence or eigenvalues. To come up with a proof that extends to tensors, we use the decomposition definition where we can rewrite the matrix as:
$$I_{d} = \sum_i^{M-1}f_i(x) \cdot g_i(y)$$
Recall that we can think of each $f_i(x) \cdot g_i(y)$ like two vectors $f_i \cdot g_i^\top$. Therefore, there must exist a function $u: [M] \rightarrow \mathbb{R}$ that is perpendicular to all $f_1,f_2,...,f_{M-1}$. Therefore, we know that:
\begin{align*}
    u^\top \mathds{I}_d &= u^\top (\sum_i^{M-1}f_i \cdot g_i^\top)\\
    &= \sum_i^{M-1}(u^\top \cdot f_i) \cdot g_i^\top\\
    &= 0
\end{align*}
However, this is a contradiction since the result should be $u^\top$. We extend this to tensors.
\bigskip

First we show that $SRank(\mathds{I}_{M\times M \times M}) \leq M$. This is because we can rewrite the tensor as follows:
$$\mathds{I}_{M \times M \times M} = \sum_{a=1}^M \mathds{1}(x=a) \cdot \mathds{1}(y=a) \cdot \mathds{1}(z=a)$$
Now we show that $SRank(\mathds{I}_{M\times M \times M}) \geq M$:
\begin{proof}
Suppose $SRank(I) < M$. Then we can write it as follows:
\begin{align*}
I(x,y,z) = \sum_{i=1}^{r_1} f_i(x)\widetilde f_i(y,z) + \sum_{i=1}^{r_2} g_i(y)\widetilde g_i(x,z) \\
    \quad + \sum_{i=1}^{r_3} h_i(z)\widetilde h_i(x,y)
\end{align*}
Where $r_1 + r_2 + r_3 = r$. First, we find a new "canceling" function $F$ such that $\langle f_i, F \rangle = 0$ for $i=1,...,r_1$ and $F$ has at least $M-r_1$ non-zero values. We argue that such an $F$ must always exist. This is because. First it follows that if a set of vectors has rank $r_1$ where $r_1 < M$, then there must be a function/vector that is perpendicular to it. We argue that one of these vectors must have at least $M-r_1$ nonzero entries. Note that the span of all vectors $f_i$ is at most $r_1$ and the span of all vectors not in the span is $M-r_1$. Since the perpendicular vectors span $M-r_1$, you must be able to find a vector with that many non-zero entries.

$\quad$ We define a new matrix:
\begin{align*}
    G(y,z) &= \sum_{x\in [M]} I(x,y,z) \cdot F(x)\\
    &= \sum_{x\in [M]}(\sum_{i=1}^{r_1} f_i(x)\widetilde f_i(y,z) + \sum_{i=1}^{r_2} g_i(y)\widetilde g_i(x,z) \\
    &\quad + \sum_{i=1}^{r_3} h_i(z)\widetilde h_i(x,y))F(x)
\end{align*}
This is the matrix taken when we sum over all $x$ values. It is essentially the analog of the the $u^\top \cdot \mathds{I}_d$ from the matrix example. The resulting function is over just $y$ and $z$, giving us:
\begin{align*}
    G(y,z) &= \sum_{x\in [M]}\mathds{I}_d (x,y,z) \cdot F(x)\\
        &= \sum_{i=1}^{r_2}g_i(y) (\sum_{x\in [M]}\widetilde{g_i}(x,z)\cdot F(x)) + \sum_{i=1}^{r_3}h_i(z)(\sum_{x\in [M]}\widetilde{h_i}(x,y)\cdot F(x))
\end{align*}
We can visualize this new matrix as follows:
$$\begin{pmatrix}
F(1) & 0 & \cdots & 0 \\
0 & F(2) & \cdots & 0 \\
\vdots & \vdots & \ddots & \vdots \\
0 & 0 & \cdots & F(n)
\end{pmatrix}$$
This is because the original tensor is one ONLY when $x = y = z$ and a $0$ everywhere else. So therefore, taking the summation over all $x \in [M]$ should yield a $1$ only once in the new matrix, when the $y$ and $z$ values are equal to it. These $1$'s are then multiplied by $F(x)$ which results in the diagonal being $F(x)$.

\quad As stated earlier, there are at least $M-r_1$ values of $F(x)$ that are non-zero. We analyze the rank of $G$. Firstly, the rank of $G$ must be equal to the number of entries on the diagonal. This follows since there are at least $M-r_1$ linearly independent rows, one for each non-zero entry. So we get the following:
$$M-r_1 \leq Rank(G)$$
Secondly, we know that the final equation turns $\widetilde{g_i}(x,z)$ into an equation just over $z$ and $\widetilde{h_i}(x,y)$ just over $y$. Because of this, we can rewrite it as $r_2 + r_3$ terms in the form of $f'_i(y)g'_i(z)$, which implies that:
$$Rank(G) \leq r_2 + r_3$$.
This equality gives us:
\begin{align*}
    M-r_1 &\leq Rank(G) \leq r_2 + r_3\\
    M-r_1 &\leq r_2 + r_3\\
    M &\leq r_1 + r_2 + r_3
\end{align*}
And since the assumption was that $r_1 + r_2 + r_3$ was at most $M-1$, we get a contradition, proving that the identity tensor must have slice rank at least $M$.
\end{proof}
